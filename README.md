# OXT: Open-X-Tactile Dataseet Repository

Official website: https://open-x-tactile.github.io/

Open-X-Tactile (OXT) is a project for collecting, organizing, and sharing tactile-centered manipulation data.

- `OXT-Contribution`: materials for dataset contributors, including submission guidelines, reference documents, and example submission files.
- `OXT-QC`: tools for checking OXT submissions, including metadata precheck, VLM-based review, and 4D visualization.
